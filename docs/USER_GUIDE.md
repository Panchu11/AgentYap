# YapMate User Guide

## 🚀 Getting Started

### Installation

1. **Download YapMate**
   - Visit the Chrome Web Store (coming soon)
   - Click "Add to Chrome"
   - Confirm installation

2. **Setup API Key**
   - Get a free API key from [Fireworks AI](https://fireworks.ai)
   - Click the YapMate extension icon
   - Go to Settings (⚙️)
   - Enter your API key (starts with "fw_")
   - Click "Save Settings"

3. **Test Your Setup**
   - Click "Test API Key" to verify configuration
   - You should see "✅ API key is valid!"

### First Use

1. Navigate to [X.com](https://x.com) or [Twitter.com](https://twitter.com)
2. Click the YapMate extension icon in your browser toolbar
3. The sidebar will open showing tweets from the current page
4. You're ready to start generating AI replies!

## 🎯 Core Features

### Crypto/General Mode Toggle

**Crypto Mode (₿)**
- Generates crypto-focused replies
- Automatically includes relevant project mentions (@)
- Adds appropriate tickers ($BTC, $ETH, etc.)
- Uses crypto-specific hashtags (#DeFi, #Bitcoin, etc.)
- Perfect for crypto Twitter conversations

**General Mode (💬)**
- Generates general topic replies
- Focuses on the actual conversation topic
- Uses appropriate general hashtags
- Ideal for non-crypto discussions

**How to Toggle:**
- Click the toggle switch in the header
- Green = Crypto Mode, Gray = General Mode
- Your preference is automatically saved

### Reply Tones

Choose from four distinct reply tones:

**🧠 Smart**
- Analytical and insightful responses
- Shows deep understanding of topics
- Professional yet engaging
- Great for serious discussions

**😂 Funny**
- Witty and entertaining replies
- Includes appropriate humor and memes
- Crypto Twitter culture references (in Crypto Mode)
- Perfect for light-hearted conversations

**💼 Serious**
- Professional and direct responses
- Adds value to conversations
- Formal tone with clear insights
- Ideal for business discussions

**🚀 Degen**
- Bold and energetic replies
- Uses crypto slang (LFG, WAGMI, etc.) in Crypto Mode
- High-energy responses
- Perfect for hype and excitement

### Theme Options

**Light Theme (☀️)**
- Clean, bright interface
- Easy on the eyes during day use
- Professional appearance

**Dark Theme (🌙)**
- Dark background with light text
- Reduces eye strain in low light
- Modern, sleek appearance

## 📱 Using YapMate

### Generating Replies

1. **Select a Tweet**
   - Tweets from the current page appear in the sidebar
   - Each tweet shows author, content, and engagement metrics

2. **Choose Your Settings**
   - Toggle Crypto/General mode as needed
   - Select your preferred tone (Smart, Funny, Serious, Degen)

3. **Generate Reply**
   - Click "✨ Generate AI Reply"
   - Watch the typewriter effect as your reply appears
   - The AI analyzes the tweet and generates a contextual response

4. **Use Your Reply**
   - **📋 Copy**: Copy to clipboard for manual pasting
   - **🔄 Rewrite**: Generate a different version of the same reply
   - **📝 Fill**: Automatically fill Twitter's reply box (when available)

### Advanced Features

**Project Detection**
- YapMate automatically detects crypto projects mentioned in tweets
- Includes official handles (@bitcoin, @ethereum, etc.)
- Adds relevant tickers ($BTC, $ETH, $SOL, etc.)
- Uses appropriate hashtags (#Bitcoin, #DeFi, #Solana, etc.)

**Smart Fallbacks**
- If the AI service is unavailable, YapMate uses smart fallback responses
- Ensures you always have a reply option
- Maintains context and tone preferences

**Real-time Updates**
- Tweets refresh automatically as you scroll
- New tweets appear in the sidebar instantly
- Click the refresh button (🔄) for manual updates

## ⚙️ Settings & Configuration

### API Configuration

**Fireworks AI Setup**
1. Visit [fireworks.ai](https://fireworks.ai)
2. Create a free account
3. Navigate to API Keys section
4. Generate a new API key
5. Copy the key (starts with "fw_")
6. Paste into YapMate settings

**Testing Your API Key**
- Use the "🧪 Test API Key" button
- Verifies your key is valid and has credits
- Shows clear success/error messages

### Preferences

**Saved Settings**
- Crypto/General mode preference
- Theme selection (Light/Dark)
- API key (securely stored)

**Privacy**
- All settings stored locally in Chrome
- No data sent to YapMate servers
- API key encrypted in Chrome's secure storage

## 🔧 Troubleshooting

### Common Issues

**"No tweets found"**
- Make sure you're on X.com or Twitter.com
- Try refreshing the page
- Click the refresh button in YapMate

**"API key not configured"**
- Go to Settings and enter your Fireworks AI API key
- Make sure the key starts with "fw_"
- Test the key to verify it's working

**"Extension context invalidated"**
- Refresh the Twitter page
- Close and reopen the YapMate sidebar
- If persistent, restart your browser

**Tweets not loading**
- Check your internet connection
- Refresh the Twitter page
- Try clicking the refresh button in YapMate

**Copy button not working**
- Make sure you've granted clipboard permissions
- Try right-clicking and selecting "Copy"
- Some browsers require user interaction for clipboard access

### Performance Tips

**Optimize Performance**
- Close unused browser tabs
- Keep YapMate sidebar closed when not in use
- Clear browser cache if experiencing slowdowns

**Best Practices**
- Use Crypto Mode for crypto-related tweets
- Switch to General Mode for non-crypto content
- Choose appropriate tones for different conversations
- Review generated replies before posting
