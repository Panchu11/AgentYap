# 💬 YapMate

AI-powered Twitter reply generator for crypto Twitter. Generate authentic, engaging replies with the perfect tone and project mentions.

## 🚀 Features

- **Smart Reply Generation**: 4 tone options (Smart, Funny, Serious, Degen)
- **Auto Project Detection**: Automatically includes relevant handles, tickers, and hashtags
- **One-Click Integration**: Seamlessly integrates with X.com interface
- **Copy & Rewrite**: Easy copy-to-clipboard and reply rewriting
- **Fallback System**: Works even when API is down

## 🛠 Installation

### For Users
1. Download from Chrome Web Store (coming soon)
2. Get a free API key from [OpenRouter](https://openrouter.ai)
3. Configure your API key in extension settings
4. Start generating replies on X.com!

### For Developers
1. Clone this repository
2. Install dependencies: `npm install`
3. Build the extension: `npm run build:extension`
4. Load unpacked extension in Chrome from `dist` folder

## 🔧 Configuration

1. Click the YapMate extension icon
2. Go to Settings (⚙️)
3. Enter your OpenRouter API key
4. Save and start using!

## 🎯 Usage

1. Navigate to X.com
2. Look for "💬 Reply with AI" buttons below tweets
3. Click to select a tweet
4. Choose your tone and generate a reply
5. Copy and paste into Twitter's reply box

## 🔒 Privacy

- Your API key is stored locally in Chrome
- No data is sent to our servers
- All AI processing happens through OpenRouter
